# Локальная история исходников

Ветка `main` содержит последовательные снимки исходников из реально сохранённых ZIP:

1. `v1.0.0` — `Releases/Legacy/TarkovOffline-Windows.zip`.
2. `v1.1.0` — `Releases/Legacy/TarkovOffline-Windows-updated.zip`.
3. `v1.4.0` — `Releases/1.4.0/TarkovOffline-1.4.0-Windows.zip`.
4. `v1.5.0` — `Releases/1.5.0/TarkovGPS-1.5.0-Windows.zip`.
5. `v1.6.0` — `Releases/1.6.0/TarkovGPS-1.6.0-Windows.zip`.
6. `v1.7.0` — `Releases/1.7.0/TSUYU-EFTGPS-1.7.0-Windows.zip`.

Пути указаны относительно соседней папки `outputs`. Версии 1.2 и 1.3 не восстановлены: отдельных сохранённых архивов нет. Даты коммитов соответствуют восстановлению истории, а не предполагаемым датам старых выпусков.

В каждую версию применена текущая политика `.gitignore`. Содержимое кода берётся из соответствующего архива; полные пакеты выпусков остаются неизменными. В ранних ZIP имена CMD-файлов прочитаны с учётом исходной OEM-кодировки.

Для дальнейшей работы создана и выбрана ветка **`codex/eft-gps-1.7-development`**. В ней дополнительно сохранены текущие изменения инструментов разработки и сборки после версии 1.7.0.

В Git входят код HTML/CSS/JS/C#, тесты, документация, иконка приложения и инструменты сборки. Загруженная база `public/data`, изображения и карты `public/assets`, зависимости, runtime, сохранения, временные файлы, установщики и ZIP в Git не входят. Для запуска офлайн они по-прежнему есть локально и в полных пакетах выпусков.

Проверяемый список коммитов и тегов: `../../work/source-history-restoration.json`. История создаётся локально; отправка на GitHub в эту операцию не входит.
