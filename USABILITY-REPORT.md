# EFT GPS 1.10.0 — отчёт о проверке / Verification report

12 ноября 2026. Разработка выполнена в `feature/usability-overlay-beta`, после повторных проверок подготовлена к обычному объединению в `main`. История не переписывается. Выпуск: [v1.10.0](https://github.com/TsuyuDX/eft-gps/releases/tag/v1.10.0).

## Изменения

1. Компактная плашка об использовании ИИ в начале обоих README.
2. Единый поиск из любого раздела: Ctrl+K и кнопка быстрого доступа. Предметы, задания, карты, убежище, торговцы, боссы, события, сезоны и новости; части слов, несколько ключевых слов, регистронезависимые RU/EN-названия. Использует существующие JSON и кеш. Точное совпадение на другом языке имеет приоритет перед случайным фрагментом.
3. Возврат к спискам предметов и заданий сохраняет реальные элементы управления, фильтры, сортировку, страницу и прокрутку. Кеш ограничен восемью списками; после смены языка или режима используется отдельное состояние. Прокрутка остальных страниц также запоминается в сеансе.
4. Существующий Overlay подключён через Настройки → Экспериментальное. Beta выключена по умолчанию; выбор сохраняется существующим механизмом настроек. Выключение закрывает только собственный процесс. При выключенной Beta фоновый процесс не запускается. Закрытие службы завершает её оверлей. Выбор режима в оверлее больше не перезаписывает основной профиль на диске.
5. Кнопки «Включить GPS» / «Отключить GPS» сразу управляют существующим считыванием скриншотов. Исправлены гонки при отключении во время чтения файлов и логов. Автосъёмка остаётся отдельным явным действием.
6. Уточнены тексты настроек, GPS, сведения о метках, названия сторон, сообщения об обновлении, новая английская локализация. Канонические игровые названия и тексты источника не заменяются произвольными переводами. Пасхальная тема и оба стиля меток сохранены.
7. Аудит карт и пределы достоверности описаны отдельно в [MAP-AUDIT.md](MAP-AUDIT.md).
8. Обновлятор при запуске получает сведения о выпуске и манифест. Версия, список изменений и кнопки «Обновить» / «Позже». Только явное нажатие запускает загрузку и отдельное окно обновления. Список изменений вставляется как текст, без выполнения HTML. Существующие SHA-256, проверка путей, дельта-пакеты, резервная копия и откат сохранены. Ошибка не удаляет текущую рабочую версию; проверенный пакет сохраняется при недоступном установщике.
9. Нижняя панель показывает зелёную точку «Онлайн» или красную «Оффлайн» / Online or Offline. Событие отключения сети применяется сразу; доступность интернета проверяется небольшим фиксированным запросом к Microsoft NCSI, максимум раз в минуту у видимого окна. Служба кеширует и объединяет запросы. Нет обращений к GitHub ради этого индикатора. Запрос не содержит настроек, прогресса, логов или скриншотов. Источник метода: [Microsoft NCSI FAQ](https://learn.microsoft.com/en-us/windows-server/networking/ncsi/ncsi-frequently-asked-questions). Блокировка проверочного адреса может выглядеть как отсутствие сети; это только индикатор, он не отключает функции приложения.

## Проверки

- Автоматические Node.js-тесты: **92 пройдены, 0 ошибок, 0 пропусков**.
- Сборка Windows: запускатели, WebView2-оболочка, установщик и существующий Overlay успешно скомпилированы.
- Нативный тест установщика: хеши, версия, текущая папка установки, сохранение профиля, настроек Beta и GPS, пакет изменений, отмена/откат, запрещённые пути и файловые перенаправления.
- Нативный тест Overlay: пропуск мыши, отсутствие перехвата фокуса, смена и освобождение кадров.
- Реальный интерфейс: поиск AI-2 сначала находит аптечку АИ-2; список предметов вернулся на ту же страницу и scrollTop 3077 с прежними поиском/фильтром/сортировкой. Overlay запущен и выключен из настроек; после выключения running=false. GPS выключен и включён повторно. Проверены RU/EN и Night Factory PvE. В журнале браузера ошибок нет.
- Проверка реального GitHub Release с фиктивной старой версией: доступна 1.9.1; установщик не запущен, папок загрузки не создано. Установленная пользовательская копия не обновлялась тестом.
- Индикатор сети: реальная проверка вернула online=true, интерфейс показал зелёный «Онлайн». Оффлайн, восстановление связи, RU/EN, сетевые ошибки, перенаправления и страница авторизации проверены изолированными тестами без отключения сети компьютера.
- `npm audit --omit=dev`: 0 известных уязвимостей рабочих зависимостей. Это не обещание отсутствия всех возможных уязвимостей.
- Проверка файлов перед публикацией: временные данные, userdata и приватные ключи исключены; контрольный состав checkout обновлён: проверены SHA-256 всех **70 619 файлов**, около 2,7 ГБ.
- После UI-тестов исходные файлы настроек тестовой копии восстановлены и сверены по SHA-256. Установленная программа, личный прогресс и архив на рабочем столе не изменялись.

## Ограничения

- Не проводился новый реальный рейд с включённым античитом: совместимость Overlay с каждой конфигурацией игры не гарантируется. Нужен оконный режим без рамки; между скриншотами GPS не измеряет новую позицию.
- Опасные границы и дополнительные сезонные точки остаются неподтверждёнными в игре; см. аудит карт. Полная ручная проверка каждой игровой статьи/перевода не проводилась; названия источника сохранены.
- Новая версия публикуется проверяемой сборкой GitHub Actions после успешных тестов. Старые установленные версии не получают новую логику согласия до обновления на 1.10.0.
- Защита Windows не отключалась, исключения не создавались, заблокированные файлы не восстанавливались. Гарантировать отсутствие антивирусных предупреждений у неподписанной сборки нельзя.
- Лицензии библиотек и существующие уведомления об источниках сохранены. Разрешение на распространение сторонних игровых карт, текстов и иллюстраций этой проверкой не устанавливается.

## English

Version 1.10.0 adds bilingual global search, preserved list navigation, an immediate GPS toggle, opt-in integrated Overlay Beta, explicit update approval, corrected reference map variants, provenance notices and an online/offline indicator. Existing architecture, profile storage and rollback safeguards remain in use. Native components compile; automated, native and UI checks are recorded above. Current in-game map accuracy, a new anti-cheat raid test and complete manual proofreading of every reference article remain outside verified coverage. The 1.10.0 release is built and verified by GitHub Actions after tests pass. Older installations retain their previous update behaviour until upgraded.
