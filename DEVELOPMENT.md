# Основа и рабочая ветка

- `main` — проверенная основа. Её состояние дополнительно закреплено тегом `stable-1.7.1`; прежняя основа сохранена как `stable-1.7.0`.
- `codex/eft-gps-1.7-development` — текущая разработка. Все новые изменения и коммиты делать здесь либо в отдельной ветке `codex/...` от неё.
- В `main` переносить только проверенный результат после явного решения о выпуске. Коммиты рабочей ветки сами по себе `main` не меняют.

В Sublime Merge текущая ветка показана сверху. Для разработки должна быть выбрана `codex/eft-gps-1.7-development`. В графе `main` остаётся на последнем проверенном выпуске; рабочая ветка продвигается дальше с новыми коммитами. После публикации их вершины могут совпадать.

Перед переключением версии закрыть приложение и сохранить код через Commit или Stash. Для отката приложения использовать теги завершённых версий; личный прогресс экспортировать отдельно.

## Защита от случайного коммита

В этом локальном репозитории установлен `pre-commit` hook, который запрещает обычные коммиты в `main`, `master` и состоянии detached HEAD. В рабочей ветке коммиты разрешены. Это защита от случайного действия, а не серверное ограничение GitHub.

После клонирования на ноутбук Git не устанавливает hooks автоматически. Переключиться на рабочую ветку и выполнить:

```bat
runtime\node.exe scripts\install-git-guard.mjs
```

Скрипт не заменяет чужие hooks. Hook копируется в служебную папку Git и сохраняется при переключении на стабильную `main`. На GitHub для main запрещены Force Push и удаление; это относится и к администратору. Обычные fast-forward обновления проверенного результата разрешены.
