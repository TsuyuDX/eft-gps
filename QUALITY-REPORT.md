# Проверка EFT GPS 1.12.0

Дата: 14 ноября 2026. Архитектура сохранена: локальная служба Node.js, HTML/CSS/JavaScript и оболочка Windows WebView2.

## Изменения

- Overlay перенесён внутрь основного процесса приложения. Отдельный `EFTGPSOverlay.exe` исключён из поставки. Раздел **Настройки → Overlay** содержит переключатель Beta, большую и компактную карту, предпросмотр положения, размер, прозрачность, горячую клавишу, карту, режим, частоту кадров, следование GPS и подписи выходов. Настройки сохраняются; по умолчанию Overlay выключен.
- При выключении освобождаются окно, WebView, таймеры отображения и горячая клавиша. Скрытая карта не захватывает кадры. Ожидание неисправной карты ограничено 30 секундами. Нет отдельного запускаемого процесса Overlay; обычные дочерние процессы WebView2 остаются частью технологии приложения.
- Повреждённый профиль восстанавливается из последней корректной резервной копии. Запись атомарная; повреждённый файл не заменяет исправную копию. Ошибки сохранения явно отображаются.
- Недоступность браузерного хранилища не блокирует сохранение настроек и прогресса в локальной службе.
- Устранены гонки при смене режима и быстрых переходах между страницами. Устаревший ответ больше не заменяет текущую страницу или базу другого режима.
- Поиск учитывает обновляемые новости, сезоны и промокоды; исправлено сопоставление идентификаторов вроде AI-2 и работа Escape / Ctrl+K.
- Добавлена отмена скачивания обновления с очисткой неполного файла и возможностью повторной загрузки. Записи параллельных блоков в общий файл выполняются последовательно. Установка остаётся добровольной.
- Исправлены повторяющиеся новости из разных официальных лент, названия английских вариантов карт, возраст позиции GPS, фокус после закрытия диалогов и освобождение изображений предпросмотра.
- Новые подписи Overlay редактируются в `public/locales/overlay-client.js`; быстрые переопределения — в `public/locales/custom.js`.

## Проверки

- 134 автоматизированных теста Node.js: все пройдены. Проверены регрессии встроенного Overlay, профиля и офлайн-снимка события.
- Проверка RU/EN: 1116 подписей и 49 шаблонов; нативные словари проверены.
- Сборка оболочки, запускателей и установщика Windows: успешна.
- `test/installer.ps1`: новая установка, обновление с сохранением данных, защита от подмены пакета и выхода за каталог, откат при заблокированном файле.
- `test/setup-transfer.ps1`: HTTP-диапазоны, ограниченные повторы, продолжение загрузки, восстановление повреждённых блоков, единственный писатель и отмена.
- `test/overlay.ps1`: встроенное владение окном, отсутствие отдельной записи на панели задач, применение настроек, корректное освобождение, пропуск мыши и сохранение фокуса.
- В интерфейсе проверены первый запуск, поиск и переход к предмету, управление GPS, английский язык, настройки Overlay, показ/скрытие Alt+M и выключение. При включённом Overlay отдельный `EFTGPSOverlay.exe` отсутствовал в процессах.
- `npm audit --omit=dev`: известных уязвимостей производственных зависимостей не обнаружено. Это не гарантия отсутствия любых уязвимостей.

## Данные и ограничения

Проверено 30 вариантов карт, 34 979 меток: некорректных координат, отсутствующих иконок и пустых названий не обнаружено. Все категории совпадают с текущим справочником после устранения подтверждённых дублей камер. Все 714 записей опасностей также совпадают. Слои заданий сверены в 60 файлах RU/EN и PvP/PvE; новые точки добавлены на соответствующие карты. Для первой офлайн-установки добавлены 18 двуязычных заданий с локальными иллюстрациями. Совпадение со справочником не является точным замером границ опасностей в рейде. Подробности: [MAP-AUDIT.md](MAP-AUDIT.md), [источники подтверждений](VERIFICATION.md).

Обновлена сохранённая информационная лента. Доступны официальные Telegram и Steam, а текущая активность события отдельно сверяется с явным статусом на странице справочника. Официальное происхождение публикации и проверка текущей активности обозначены раздельно. Сайт, форум и YouTube временно недоступны в этом проходе; Twitch, TikTok и Reddit требуют подходящего доступа API. Слухи, неизвестные сроки и неподтверждённые промокоды не объявлены действующими. Предыдущие корректные данные сохраняются при сбое сети.

Overlay проверен как окно Windows, но не в настоящем рейде. Совместимость со всеми настройками игры и античитом не установлена. Выбранные задания основного окна пока не синхронизируются с Overlay. Автоматическая отправка диагностики не подключена; настройки безопасности Windows и файлы самой игры не изменялись.

## English

Overlay is now owned by the main EFT GPS desktop process, with a dedicated Settings tab and persistent controls. Profile recovery, storage fallback, navigation races, search indexing and cancellable update downloads were improved. JavaScript, native setup/downloader, Overlay ownership and input-passthrough checks passed. All map categories match the reference after correcting demonstrated camera duplicates. The offline snapshot includes 18 bilingual event tasks. No game files or Windows security settings were changed. Evidence and verification scope are documented in VERIFICATION.md.
