# TarkovHead Offline

Локальное приложение Windows с интерфейсом на HTML, CSS и JavaScript, созданное по TarkovHead. Интернет для обычной работы не нужен: данные, изображения, карты и руководства находятся в папке приложения.

## Запуск

1. Если используете ZIP, распакуйте **всю папку**, а не только EXE.
2. Запустите **Tarkov Offline.exe**. Откроется отдельное окно Microsoft Edge без обычной панели вкладок.
3. Папку можно перенести на другой компьютер Windows вместе со всем содержимым. Node.js включён в `runtime`, устанавливать его не требуется. Нужен установленный Microsoft Edge; при его отсутствии откроется браузер по умолчанию.

Локальный адрес: `http://127.0.0.1:38471`. Приложение слушает только этот компьютер. После закрытия всех окон приложения локальный процесс завершится примерно через две минуты.

## Что работает

- 5 480 позиций в каждом из каталогов PvP и PvE: поиск, категории, сортировка, избранное, карточки с характеристиками, ценами, обменами и производством.
- 570 заданий PvP и 566 заданий PvE: фильтры, прохождения, цели, награды, отметки завершения.
- 15 карт: масштаб, перемещение, этажи, выходы, спавны, контейнеры, свободный лут, двери, опасности, квестовые метки, сезонные документы, собственные метки. Все 16 уровней Ледокола, три уровня Лаборатории и Лабиринт сохранены в локальные изображения.
- Убежище: уровни строительства, требования, описания, бонусы и рецепты в сохранённых справочных страницах.
- Трекер предметов, который учитывает завершённые задания и построенные уровни убежища.
- Боссы, торговцы с поиском по ассортименту и уровнями лояльности, события, сезоны, архив новостей.
- Калькулятор сезонных модификаторов с балансом очков и проверкой несовместимости.
- Независимый прогресс PvP и PvE, заметки, экспорт и импорт резервной копии JSON.

## Границы этой версии

Это самостоятельная локальная реализация основных разделов, **не полная функциональная копия серверной части TarkovHead**. Вход в аккаунт сайта, облачная синхронизация, удалённое управление сайтом через TarkovMonitor, серверные уведомления о сбросе ассортимента и спутниковый вариант карт не реализованы. Собственный локальный GPS добавлен в версии 1.1.0. Графика растровых карт сохранена на фиксированном уровне детализации; при сильном приближении она менее чёткая, чем онлайн-тайлы оригинала.

Цены, шансы боссов и события соответствуют дате снимка. Новые изменения игры появятся только после обновления базы. Справочные статьи и ассортимент торговцев сохранены из общего снимка PvP; предметы, задания, карты и требования трекера имеют отдельные данные PvE. Некоторые изображения недоступны у исходных поставщиков: вместо них показывается заглушка, список находится в «Данные и прогресс». Все основные карточки и задания загружены.

Внешние ссылки, например на Discord, покупку игры и Wiki, требуют интернета. Они открываются только по явному нажатию.

## GPS — версия 1.1.0

1. Откройте раздел **GPS** в приложении.
2. Укажите папку **внутриигровых** скриншотов. Обычный путь: Documents → Escape From Tarkov → Screenshots. Если папки ещё нет, сначала сделайте скриншот в игре. Кнопка «Выбрать…» открывает выбор папки Windows.
3. При желании укажите \Logs установленной игры: это позволяет читать карту, режим и события начала/конца рейда. Без логов выберите карту вручную.
4. Включите чтение скриншотов и сохраните настройки. Нажмите назначенную на скриншот клавишу в игре: на карте появится ваша позиция.
5. Для автообновления задайте интервал 1–30 секунд и **ту же клавишу, которая назначена на скриншот в Tarkov**. Доступны PrintScreen, F12, F11 и Insert. После начала рейда нажмите «Начать автосъёмку». Если логи не подтвердили рейд, потребуется вручную отметить «Подтверждаю, что я уже в рейде».

Автосъёмка запускается только по кнопке и выключена после каждого запуска приложения. Отдельный Windows-процесс отправляет выбранную клавишу только когда активное окно принадлежит EscapeFromTarkov. При переключении окон он приостанавливается, при завершении рейда по логам или потере связи с приложением останавливается. В ручном режиме без логов **после рейда нажмите «Остановить»**. На карте можно включить выбор этажа по высоте и следование за своей меткой.

Координаты берутся из имени файла, содержимое изображений не читается и никуда не отправляется. Между скриншотами отображается последняя измеренная позиция, её возраст всегда показан. Старые координаты помечаются как устаревшие. Частые скриншоты расходуют место на диске; приложение их не удаляет. Позиции других игроков и NPC не извлекаются. Автосъёмка не читает память, не подключается к процессу игры и не меняет игровые файлы.

**Проверено автоматически:** разбор имён, поворота и логов, частичные записи журналов, остановка на конце рейда, выбор этажа, отсутствие автоматического запуска нажатий. Windows-запускатель прошёл самопроверку без отправки клавиш. **В настоящем рейде автосъёмка ещё не проверена:** клиент может не принять программное нажатие; в таком случае остаётся ручное нажатие клавиши. Не обещается непрерывный поток координат: частота измерений определяется появлением файлов.

Исходники: public/core/gps-format.js — форматы; server/gps.mjs — локальная служба; public/features/gps.js — настройки; public/features/map-gps.js — метка; scripts/GpsCapture.cs — Windows-запускатель. Формат файлов и событий сверен с [первичными исходниками TarkovMonitor](https://github.com/the-hideout/TarkovMonitor/blob/master/TarkovMonitor/GameWatcher.cs); реализация самостоятельная.

## Где хранится прогресс

`userdata/profile.json` — основной файл, `userdata/profile.json.bak` — предыдущая запись. Дополнительная копия хранится в браузере. Для переноса используйте кнопку резервного копирования в приложении; она включает оба режима, заметки, избранное и собственные метки.

Импорт заменяет профиль целиком и запрашивает подтверждение. Обновление базы не затрагивает `userdata`.

## Обновление

Закройте приложение и запустите **Обновить базу.cmd**. Требуется интернет и свободное место для второй копии базы. Загрузка большого количества изображений может занять время.

Новый снимок сначала собирается в `update-staging`. При сбое основных данных старая база остаётся на месте. Успешное обновление сохраняет предыдущую базу в `snapshot-backup-*`. Если обновление прервалось, проверьте и переименуйте `update-staging` перед повтором. Скрипты рассчитаны на текущий формат публичных интерфейсов источника; при его изменении их потребуется адаптировать.

## Исходный код

Откройте `TarkovOffline.code-workspace` в VS Code.

```text
public/
  index.html              оболочка HTML
  style.css               адаптивный интерфейс
  app.js                  маршрутизация и навигация
  core/
    data.js               работа с локальным снимком
    state.js              сохранение, профили и резервные копии
    domain.js             расчёты трекера, координат и модификаторов
    ui.js                 безопасная разметка и компоненты
  features/
    catalog.js            предметы, цены и рецепты
    quests.js             задания и цели
    maps.js               интерактивные карты
    progress.js           трекер, убежище, сезонный билд, настройки
    articles.js           справочные материалы и торговцы
  data/                   JSON-снимок, отдельные данные PvP/PvE
  assets/                 локальные изображения, шрифты и карты
server.mjs                локальный сервер и запись прогресса
scripts/
  Launcher.cs             исходник Windows-запускателя
  snapshot.mjs            основной загрузчик
  modes.mjs               отдельные данные PvE
  extra-articles.mjs      полный архив статей
  prepare-articles.mjs    восстановление страниц и локальные ссылки
  guide-assets.mjs        иллюстрации прохождений
  tile-maps.mjs           автономные растровые карты
  finalize.mjs            итоговый индекс базы
  repair-assets.mjs       повторная загрузка недоступных изображений
  refresh.mjs             обновление через промежуточную папку
test/                     проверки логики
runtime/                  Node.js для Windows и его лицензия
```

У интерфейса нет сборщика, React и внешних CDN. Модули загружаются напрямую из локальных файлов. `linkedom` используется только при подготовке снимка, Prettier — для форматирования исходников. Основной сервер использует стандартные модули Node.js.

Запуск из исходников: `runtime\node.exe server.mjs`.

Проверки: `runtime\node.exe --test test/*.test.mjs`.

Пересборка запускателя:

```powershell
& "$env:WINDIR\Microsoft.NET\Framework64\v4.0.30319\csc.exe" /nologo /target:winexe /reference:System.Windows.Forms.dll '/out:Tarkov Offline.exe' '.\scripts\Launcher.cs'
```

## Проверка

Проверены расчёты координат, исключение завершённых требований из трекера, конфликты модификаторов и ограничение доступа сервера папкой `public`. В интерфейсе проверены поиск, карточка предмета, сохранение задания после перезагрузки, карты и этажи, требования убежища, торговцы и переключение режима. Дата и результаты снимка находятся в `public/data/manifest.json`.
