# Tarkov Offline 1.4.0

Самостоятельный справочник Escape from Tarkov для Windows с интерфейсом HTML/CSS/JavaScript и собственным окном Microsoft WebView2. Для обычной работы интернет не требуется.

## Установка и запуск

- Полный установщик: **TarkovOffline-1.4.0-Setup.exe**. Выберите пустую папку или папку ранее установленного Tarkov Offline. Установщик проверяет файлы, по выбору создаёт ярлык на рабочем столе и сохраняет пользовательские данные.
- Переносная версия: распакуйте **TarkovOffline-1.4.0-Windows.zip** целиком и запустите **Tarkov Offline.exe**.
- Windows 10 (1903 или новее)/11, x64, .NET Framework 4.7.2 или новее. В Windows 11 нужный .NET обычно уже есть.
- Нужен Microsoft WebView2 Runtime. Полный установщик содержит официальный автономный установщик Microsoft и запускает его только при отсутствии среды. Интернет для этого не нужен. В переносной версии он находится в runtime/MicrosoftEdgeWebView2RuntimeInstallerX64.exe.
- Отдельные драйверы, DirectX и пакеты Visual C++ этому приложению не требуются. Node.js и модуль GPS включены в пакет. .NET Framework проверяется до начала установки; если компонента нет, установщик объяснит, что его нужно добавить через Центр обновления Windows.
- Установщик оформлен в чёрной теме приложения: собственные подтверждения и выбор папки, выбор ярлыка, проверка свободного места, журнал и понятные сообщения об ошибках. Временный ZIP удаляется после установки.
- Установленный браузер Edge больше не нужен для открытия окна. Локальный сервер и Node.js включены в комплект.

## Что изменилось в 1.4.0

- Собственная оболочка WebView2: чёрная системная рамка, без вкладок, адресной строки и браузерных уведомлений. Браузерные ускорители, инструменты разработчика, масштаб страницы и строка адреса отключены на уровне оболочки.
- Копирование и редактирование текста сохранены. Меню содержит только команды работы с текстом; Esc возвращает из карточек и сворачивает развёрнутую карту. Ctrl+K открывает поиск, Alt+F4 закрывает окно.
- Возврат стрелкой, поиск торговцев, боссов и событий; страницы разделов не попадают в списки карточек.
- Настройки интерфейса и карты с вкладками, сохранением выбора и сбросом вида. Темы пока не реализованы: пункт оформления показывает текущую чёрную тему.
- Фильтры карты и внешний вид дополнительно записываются в userdata/window-settings.json; прогресс хранится отдельно.
- Русские подписи этажей, палуб и характеристик предметов; значения да/нет и проценты отображаются в читаемом виде.
- Для заданий без авторского прохождения показывается краткий план по сохранённым целям, ключам и картам. План явно обозначен и не выдаётся за материал автора.
- Установщик проверяет SHA-256 файлов, сохраняет изменяемые файлы и откатывает их при ошибке. Пакеты не могут менять userdata или выходить за папку приложения.
- Обновление базы подготавливает и проверяет новый снимок до замены текущего. При ошибке замены возвращается старый снимок. Повторное обновление не блокируется завершённой служебной папкой.

## Данные и офлайн-работа

Сохранены 5 480 предметов в каждом режиме, 570 заданий PvP, 566 заданий PvE, 15 карт, справочные статьи, изображения, торговцы, боссы, события, сезоны, убежище и трекер предметов. Цены и шансы соответствуют дате снимка, указанной в приложении.

У источника есть авторские прохождения для 505 заданий PvP и 489 заданий PvE. Для остальных доступен краткий план по целям. Некоторые изображения удалены или недоступны у поставщиков; интерфейс показывает пояснение. Повторная проверка не вернула новых иллюстраций: 59 проблемных ссылок остались недоступны, один файл уже был сохранён локально. Подробности сохранены в public/data/content-repair-report.json.

База, рисунки карт, фрагменты этажей, иконки и доступные прохождения находятся на диске. Их просмотр не зависит от доступности TarkovHead. Новые изменения игры появятся после обновления базы. Внешние ссылки открываются в отдельном браузере только по нажатию.

Это независимая локальная реализация. Вход в аккаунт TarkovHead, облачная синхронизация и серверные уведомления сайта не реализованы. Статьи и ассортимент торговцев используют общий снимок PvP, а каталоги, задания, карты и трекер разделены по режимам.

## Карты

Векторные карты сохраняют чёткость при приближении. Для растровых этажей включены доступные у источника фрагменты максимального разрешения; в окно загружаются только видимые. Иконки сохраняют читаемый размер и привязку к координатам.

Этажи затемняют основной план, зоны опасностей показываются контурами. Слои разбиты на разновидности контейнеров, предметов, выходов, точек появления, опасностей и заданий. Выбор запоминается для локации и режима. Поиск заданий открывает цели и прохождение; есть свои метки.

Разворот карты занимает всё клиентское окно приложения, без браузерного fullscreen. Кнопка возврата и Esc сворачивают карту. Панель слоёв можно скрыть и вернуть через шестерёнку.

## GPS и очистка снимков

GPS использует координаты и направление из имён внутриигровых скриншотов и журналов EFT. Память игры не читается, внедрение в клиент не используется. Пользователь подтвердил работу GPS в рейдах по выбранному сценарию.

Автосъёмка включается явно, отправляет выбранную клавишу только активному окну Escape from Tarkov и останавливается при завершении рейда, закрытии приложения или потере связи с окном. После перезапуска она выключена.

Автоочистка обрабатывает только новые подходящие скриншоты, обнаруженные в период включённой автосъёмки. Старые файлы и файлы вне этой сессии не удаляются. Координаты читаются до удаления. Ручной скриншот, сделанный во время автосъёмки, тоже может попасть в очистку — это указано в настройках GPS.

## Сохранения

- userdata/profile.json — задания, цели, избранное, убежище, предметы, свои метки и заметки для PvP/PvE.
- userdata/gps-settings.json — настройки GPS.
- userdata/window-settings.json — внешний вид и фильтры карт.
- userdata/webview2 — хранилище собственной оболочки.

Папка userdata исключена из пакетов установки. Настройки → Данные и прогресс позволяют сохранить JSON-копию прогресса и восстановить её. При смене папки приложения переносите userdata целиком. При первом переходе со старого окна Edge прогресс читается из существующего profile.json; прежние настройки вида, оставшиеся только в хранилище Edge, автоматически не извлекаются.

## Обновления

В настройках есть отдельные действия:

1. **Обновить базу** — загрузить данные из интернета в отдельной службе обслуживания. Автосъёмка остановится, окно приложения закроется. После успешной загрузки и проверки можно открыть приложение снова.
2. **Установить обновление приложения** — выбрать новый ZIP-пакет Tarkov Offline. Полноценного сервера автоматического обновления версии нет: пакет выбирает пользователь.
3. **Перезагрузить интерфейс** — перечитать интерфейс без браузерных горячих клавиш.
4. **Открыть папку приложения** — открыть файлы в Проводнике.

Обновить базу.cmd запускает ту же службу. Старый снимок сохраняется в snapshot-backup-*, изменённые файлы приложения — в work/install-backup-*. Личные файлы не удаляются. Не прерывайте установку во время замены файлов.

## Исходники и сборка

- public/core — данные, состояние, настройки и навигация.
- public/features — разделы, карты, GPS и задания.
- server.mjs и server/ — локальные API и обработка файлов GPS.
- scripts/DesktopHost.cs — окно WebView2; scripts/Launcher.cs — запуск службы и окна.
- scripts/Maintenance.cs — установщик и служба обновления.
- scripts/refresh.mjs и update-transaction.mjs — подготовка, проверка и замена базы.
- scripts/build-desktop.ps1 и build-release.ps1 — сборка окна, установщика и ZIP.
- test/ — проверки логики, базы и установщика.

Проверки: runtime/node.exe --test test/*.test.mjs; отдельно PowerShell test/installer.ps1. Сборка C# использует компилятор .NET Framework. Для пересборки WebView2 SDK 1.0.4314.35 извлекается из официального NuGet-пакета в work/webview2-sdk/package. Для форматирования исходников нужен установленный через npm пакет Prettier; он не входит в пользовательский выпуск.

Иконка: public/icons/app.ico, исходное изображение public/icons/app-source.png. Лицензии Node.js и WebView2 находятся в runtime. Игровые материалы принадлежат Battlestate Games; источники справочных данных — TarkovHead и tarkov.dev. Это не официальное приложение этих проектов.
