# EFT GPS — Overlay Beta

Начиная с 1.12.0 откройте **Настройки → Overlay** в основном приложении. Отдельный запускатель или отдельное приложение не нужны. По умолчанию функция выключена. Размер, прозрачность, положение, ручная карта или выбор по GPS, подписи и горячая клавиша сохраняются существующей системой настроек и переносятся при обновлении.

Version 1.12.0 embeds Overlay in the main desktop process. Open **Settings → Overlay**. It is off by default. Choose a large or compact map, position, size, opacity, GPS following, labels and hotkey. Settings persist through updates. Disabling it disposes the map window and renderer and releases the hotkey. No standalone Overlay executable is shipped.

Скрипт тестового запуска теперь открывает основное приложение.

Запуск: `scripts/start-overlay-test.ps1`. Скрипт использует только тестовую локальную службу на порту 38479, проверяет принадлежность службы проекту и не включает автообновление исходников.

- Выберите карту и режим PVP/PVE. Дождитесь надписи «Карта готова».
- Alt+M показывает и скрывает полупрозрачную карту. Если сочетание занято, выберите Ctrl+Shift+M или F8.
- Ползунок регулирует непрозрачность от 35 до 95%.
- Мышь и фокус клавиатуры остаются в нижнем окне. Изменения делаются в разделе Overlay основных настроек.
- Для игры нужен оконный режим без рамки. Совместимость с настоящим рейдом и античитом в этой проверке не подтверждена.
- Выключение переключателя закрывает карту и освобождает горячую клавишу. Закрытие настроек оставляет выбранное состояние. Закрытие приложения выключает карту. В автозагрузку ничего не добавляется.

Это неактивируемое окно Windows в процессе основного приложения: без внедрения в игру, чтения памяти, DLL-инъекций и глобальных перехватчиков клавиатуры. Используются RegisterHotKey и существующая локальная карта. Данные GPS поступают из прежнего механизма скриншотов; скорость и точность GPS не меняются.

Для совместимости полупрозрачного окна с WebView2 карта передаётся в окно как кадр. Частота настраивается от 0,5 до 2 секунд и не меняет интервал GPS-скриншотов. При скрытой карте захват кадров останавливается. Выбранные задания из основной вкладки пока не синхронизируются. Прежний каталог `userdata/webview2-overlay-test` сохранён для совместимости настроек.

Автоматизированные проверки: `test/overlay.ps1`. Результаты и ограничения: [QUALITY-REPORT.md](QUALITY-REPORT.md).
