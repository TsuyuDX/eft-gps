# EFT GPS — Overlay Beta

В версии разработки 1.10.0 существующий прототип подключён к основному приложению: **Настройки → Экспериментальное → Экспериментальный оверлей**. По умолчанию выключен. Выбор сохраняется существующей системой настроек и не сбрасывается обновлением. Выключение закрывает только процесс оверлея этого приложения; при выключенном состоянии он не запускается.

Development 1.10.0 integrates the existing host through **Settings → Experimental → Experimental overlay**. It is off by default, uses the existing persisted settings, and starts no overlay process while disabled. Disabling it closes only the host owned by this app instance.

Отдельный тестовый запуск по-прежнему доступен.

Запуск: `scripts/start-overlay-test.ps1`. Скрипт использует только тестовую локальную службу на порту 38479, проверяет принадлежность службы проекту и не включает автообновление исходников.

- Выберите карту и режим PVP/PVE. Дождитесь надписи «Карта готова».
- Alt+M показывает и скрывает полупрозрачную карту. Если сочетание занято, выберите Ctrl+Shift+M или F8.
- Ползунок регулирует непрозрачность от 35 до 95%.
- Мышь и фокус клавиатуры остаются в нижнем окне. Изменения карты делаются в панели прототипа.
- Для игры нужен оконный режим без рамки. Совместимость с настоящим рейдом и античитом в этой проверке не подтверждена.
- Закрытие панели выключает карту и освобождает горячую клавишу. В автозагрузку ничего не добавляется.

Это обычное отдельное окно Windows: без внедрения в игру, чтения памяти, DLL-инъекций и глобальных перехватчиков клавиатуры. Используются RegisterHotKey, неактивируемое окно и существующая локальная карта. Данные GPS поступают из прежнего механизма скриншотов; скорость и точность GPS не меняются.

Для совместимости полупрозрачного окна с WebView2 карта передаётся в окно как кадр, обновляемый раз в секунду только при открытом оверлее. При скрытой карте захват кадров останавливается. В этой версии нет режима редактирования карты поверх игры; масштаб, этаж и фильтры в панели будут дорабатываться отдельно. Выбранные задания из основной вкладки пока не синхронизируются. Профиль WebView2 прототипа хранится отдельно в `userdata/webview2-overlay-test`.
