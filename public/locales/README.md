# Как редактировать тексты EFT GPS

Быстрые правки: **`custom.js`**. Все остальные файлы ниже — основной словарь.

```js
export const customTexts = {
  "Карты": { ru: "Карты локаций", en: "Location maps" },
};
```

1. Найдите фразу через поиск VS Code по папке `public/locales`.
2. Меняйте значения **`ru`** и **`en`**. Ключ слева — постоянный идентификатор, его не переименовывайте.
3. Сохраните файл и перезапустите приложение из этой копии проекта. Уже установленная копия на компьютере использует собственные файлы.
4. Выполните `runtime\node.exe scripts/check-localization.mjs`: проверка покажет ошибки синтаксиса, пропущенные значения и повреждённые переменные.

Удалите строку из `custom.js`, чтобы вернуть основной вариант. Эти правки являются исходным кодом: храните их в Git. Обновление установленного приложения заменяет исходные словари; личные настройки языка при этом сохраняются.

## Где что находится

| Файл | Что менять |
| --- | --- |
| `custom.js` | Любые быстрые исправления с высшим приоритетом |
| `interface.js` | Общие кнопки, названия разделов, настройки, GPS и справочник |
| `diagnostics.js` | Согласие на диагностику, конфиденциальность, просмотр отчёта |
| `support.js` | История автора, поддержка и бонусы |
| `help.js` | Обучение и помощь |
| `game-info.js` | События, сезоны, промокоды, состояния проверки |
| `graphics.js`, `map-colour.js` | Цветокоррекция, галерея, пресеты |
| `app-update.js` | Предложения обновиться, загрузка, ошибки обновления |
| `overlay-client.js`, `map-gps.js` | Оверлей и GPS на карте |
| `global-search.js`, `map-search.js` | Общий поиск и поиск на карте |
| `news.js` | Подписи игровых новостей |
| `app.js`, `connectivity.js`, `markup.js`, `other-interface.js` | Дополнительные подписи, панель и состояние соединения |
| `quest-detail.js`, `event-content-client.js` | Карточка задания и обновление прохождений |
| `templates.js` | Фразы с числами и переменными: этажи, счётчики, уровни |

Над каждой записью указан файл, где она используется. Исходные фразы в компонентах остаются совместимыми ключами и резервными значениями: для обычной правки искать их в логике экрана не нужно.

## Переменные и безопасность

В `templates.js` не меняйте `source`: это образец для распознавания. Правьте `ru` и `en`, сохраняя **каждое** обозначение `__V0__`, `__V1__` и т. д. Переменные можно переставлять: например `Floor __V0__`. Сохраняйте `\n`, если нужен перенос. Не вставляйте HTML, ссылки, код или данные пользователя в подписи.

Значения словарей загружаются локально: для изменения языка интернет не нужен. Введённые заметки и текст полей не переводятся. Факты игры, названия предметов и инструкции не исправляйте наугад: сверяйте их с источниками.

## Игровые материалы и установщик

- Русские игровые данные: `public/data/regular`, `pve`, `items`, `quests`, `maps`, `articles`, `traders`; английские — соответствующие разделы `public/data/en`.
- Редакционные сведения о событиях и сезонах: `public/data/game-info.json` (`title.ru/en`, `description.ru/en` и другие подписанные поля). Полученная из сети лента может обновлять эти сведения, поэтому постоянные исправления вносятся в источник ленты.
- Собственные новости EFT GPS: `public/features/news.js`; переводы подписей — в словарях выше. Сетевые публикации сохраняют язык первоисточника.
- Установщик, окно приложения и обновлятор: `scripts/native.ru.json` и `scripts/native.en.json`. Ключ — исходная фраза, значение — исправленный текст. После правок запускайте `scripts/build-desktop.ps1`; нативные надписи встроены в EXE.
- Для сборок GitHub копии нативных словарей находятся в `.github/native`. Они должны совпадать с рабочими словарями; проверка контролирует это.

## Для разработчика

`public/core/localization.js` отвечает только за выбор языка, перевод DOM и сохранение выбора. `textPair(ru, en)` использует тот же словарь для компонентов с явными парами языков. `english-ui.js` сохраняет совместимость старых экранов, а `english-patterns.js` подставляет переменные. Не создавайте второй переводчик для нового окна.

Новая обычная подпись: добавьте запись в подходящий словарь. Для нового двуязычного компонента используйте `textPair("Исходная подпись", "English fallback")`. Уведомления, подсказки, `title`, `placeholder` и `aria-label` должны использовать те же фразы.
