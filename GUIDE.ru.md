# Быстрый старт EFT GPS

1. На главной странице репозитория нажмите «Скачать / Download». Получите EFT-GPS-Setup.exe.
2. Откройте файл и нажмите «Скачать и установить». Загрузчик сам скачает и проверит пакет.
3. Выберите папку. При обновлении используйте папку уже установленного приложения, сохранив userdata.
4. При первом запуске выберите язык и пройдите короткий обзор. В настройках GPS проверьте путь скриншотов.
5. GPS получает новую позицию после нового внутриигрового скриншота. Автосъёмка включается вручную и работает при активном окне игры.

Начиная с 1.7.1 приложение один раз при запуске проверяет более новый стабильный выпуск на GitHub. Загрузка отображается внизу окна. Окно обновления использует текущую папку и сохраняет личные данные. Без интернета приложение работает с локальной базой.

Для переноса на другой компьютер используйте установщик или полностью распакованный переносной пакет. Для разработки Clone репозитория содержит исходники, runtime, карты, базу и production-зависимости: запускайте Start EFT GPS.cmd.

Для старых версий выбирайте завершённые теги app-v1.0.0, app-v1.1.0, app-v1.4.0, app-v1.5.0, app-v1.6.0, app-v1.7.0 или v1.7.1. Экспортируйте прогресс отдельно и закройте приложение перед переключением версии. Промежуточные коммиты первой загрузки не являются готовыми сборками.

Проблемы и предложения: Issues этого репозитория. Поддержка проекта добровольна: https://boosty.to/tsuyueftgps. Приложение находится в раннем доступе и может содержать ошибки.
