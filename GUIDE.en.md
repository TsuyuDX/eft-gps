# EFT GPS quick start

1. Click Download on the repository page to get EFT-GPS-Setup.exe.
2. Open it and click Download and install. The downloader retrieves and verifies the package.
3. Choose your app folder. Select the existing installation when updating and keep userdata.
4. Select your language, follow the introduction and check the screenshot directory in GPS settings.
5. GPS updates after a new in-game screenshot. Enable automatic capture manually; it runs while the game is focused.

From 1.7.1, the app checks for a newer stable GitHub release once at launch, displays download progress at the bottom, then opens an update window for the current app directory. Personal data is preserved. Offline reference data remains usable without internet.

Use the installer or a fully extracted portable package on another PC. For development, cloning includes source, runtime, maps, reference data and production dependencies: run Start EFT GPS.cmd.

For rollback, select completed app-v1.0.0, app-v1.1.0, app-v1.4.0, app-v1.5.0, app-v1.6.0, app-v1.7.0 or v1.7.1 tags. Export progress separately and close the app before switching. Partial initial upload checkpoints are not runnable releases.

Report problems or ideas in repository Issues. Optional project support: https://boosty.to/tsuyueftgps. This early-access application may contain bugs.
